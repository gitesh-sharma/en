About the register

Every neighbourhood has a Sharmaji

The one person who can sort out any paperwork problem in five minutes flat — no fuss, no forms, just get it done. That's the idea behind this toolbox: PDF jobs that used to mean hunting for the right app, done properly, in the time it takes to open a tab.

How it actually works

Every tool here runs entirely inside your browser using open PDF libraries. When you drop a file in, it's read and processed on your own device — it never travels to a server to be merged, compressed or converted. Close the tab, and there's no copy sitting anywhere waiting to be found.

All six tools in the register are live — including password protection, which uses real AES-128 encryption rather than a cosmetic lock.

What it isn't

This isn't a clone of any existing PDF app. It's built with its own design, from the ground up, to do the handful of jobs people actually need most days — combining files, tidying up page order, shrinking a file for email, and converting between formats.
